\section{The Certified Head}\label{sec:selfevidence}\label{sec:head}
The certified head finds the \Rstock{} token from an int8 copy of $W$ evaluated at the target's own head input.

\subsection{An Error Bound for the Int8 Copy}\label{sec:envelope}\label{sec:accumulation}
The copy stores each row of $W$ as integer codes with scales, optionally keeping a few outlier columns exact. The bound must cover both the quantization error and the pass's own FP32 rounding on tensor cores, whose adders align several addends to the largest, truncate them and round once~\cite{fasi2021}, so a bound for IEEE additions~\cite{higham2002} does not apply. Lemma~\ref{lem:tree} (Appendix~\ref{app:accumulation}) bounds any summation tree whose nodes have bounded relative error, tensor cores included. Under Khattak and Mikaitis's model of Hopper~\cite{khattak2026} the tensor-core accumulation alone gives $\gamma\approx1.0\times10^{-4}$ at $D=2{,}560$; the \modelhopper's $\gamma=\ghop$ adds the split-$K$ allowance, and the \modelcons, $\gamma=\gcons$, covers it about sixfold for any summation order.

\begin{theorem}[Error bound of the copy]\label{thm:envelope}
Let row $i$ of the copy have group scales $s_{ig}$, integer codes and a set of columns kept exact, with dequantized row $\bar w_i$ and exact error $e_i=w_i-\bar w_i$. If every product is exact in the accumulator format and the pass's accumulation obeys Lemma~\ref{lem:tree}, with relative bound $\gamma_d$, $N$ internal nodes and absolute floor $\eta$, its value $\tilde z_i$ satisfies $|z_i-\tilde z_i|\le\beta_i=Q_i+\gamma_d\norm{\bar w_i}_2\norm h_2+N\eta(1+\gamma_d)\max(1,\max_gs_{ig})$, where $Q_i$ is $\norm{e_i}_2\norm h_2$ or any blockwise Cauchy--Schwarz or Hölder form.
\end{theorem}
We call $\beta_i$, the half-width of entry $i$'s interval, the copy's \emph{error bound}; proofs are in Appendix~\ref{app:proofs}. An int8 pass that also quantizes the head input and sums exactly in int32 needs no floating-point accumulation model, at the price of the input's quantization error (Theorem~\ref{thm:integer}). Either pass rounds the norms of $h$ up and the interval ends $\tilde z_i\mp\beta_i$ outward, so every computed comparison is sound (Lemmas~\ref{lem:norms} and~\ref{lem:outward}), provided the kernel evaluates the analysed operations (Table~\ref{tab:assumptions}). The bound assumes the worst alignment of $e_i$ and $h$, so it is loose: for int8 with one scale per entry its median $\beta_i$ on captured states is 1.00 logit, about 75 times the median realized error \ev{stats}. Section~\ref{sec:geometry-selfevidence} shows why it is tight enough anyway.

\subsection{Refinement Against the Stock Kernel}\label{sec:ladder}
\begin{theorem}[Refinement ladder]\label{thm:ladder}
Let levels $\ell=0,\dots,L$ supply enclosures $lo^\ell_i\le z_i\le hi^\ell_i$, exact at level $L$, and let each $f_i$ be nondecreasing. Starting from entries $S$, at each level let $\tau=\max_{i\in S}f_i(lo^\ell_i)$ and keep $\{i\in S:f_i(hi^\ell_i)\ge\tau\}$; stop when one entry remains, every kept interval is a point, or $\ell=L$, and return the smallest kept index. The result is $\min\argmax_{i\in S}f_i(z_i)$, whatever the precision or reduction order of each level; $f_i(x)=x$ gives \Rreal{} and $f_i(x)=x/T+g_i$ gives \Srace.
\end{theorem}
The Lean proof assistant checks the theorem's decision logic and both properties of its filter (it keeps every maximizer and drops only beaten entries) over scaled integers, not under IEEE rounding \ev{lean}. For \Rstock{} the filter alone would drop entries that lose only in real arithmetic (Section~\ref{sec:headcontracts}), so the certified head decides each position in five steps:
\begin{enumerate}[leftmargin=1.4em]
\item Evaluate the int8 copy for every entry and form the intervals $\tilde z_i\mp\beta_i$ (Theorem~\ref{thm:envelope}).
\item Keep as \emph{candidates} the entries with $hi_i\ge\max_jlo_j-\delta_{\max}$; given valid intervals, no other entry can be the stock token (Section~\ref{sec:headcontracts}).
\item Recompute each candidate's real logit from its BF16 row in FP64 (its tiny rounding error is added) and widen it by $G_i$ to an interval for the stock kernel's accumulator.
\item Round these intervals to BF16 and apply Proposition~\ref{prop:stockinterval}; if it fixes a token, emit it.
\item Otherwise send the position to a fallback (Section~\ref{sec:kernel-fallback}).
\end{enumerate}
The screen in step 2 changes which entries are recomputed, never which decisions stay open, because an entry it drops loses to the stock token under every admissible accumulation. How many candidates survive depends on the error bound against the logit margins; for a Gumbel race the expected number grows as $e^{4\beta}$, so exact sampling through the copy stays cheap only while $\beta$ is below about two logits (Proposition~\ref{prop:candidates}).

\subsection{Sampled Decisions Within the Contract}\label{sec:decisions}\label{sec:race}
\paragraph{The stock sampler} SGLang's seeded sampler, used when no top-$k$, top-$p$ or min-$p$ truncation is set, is already a race: after an FP32 softmax and logarithm it returns $\argmax_i(\log p_i+g_i)$ in FP64, with Gumbel noise $g_i$ computed from a 32-bit hash of (seed, position, token). This noise is a \emph{keyed field}: it can be recomputed for any token in any order, which pathwise equality with the stock sampler requires. The sampler exists only with \code{-{}-enable-deterministic-inference}. In that mode the head runs DeepGEMM's deterministic BF16 GEMM instead of cuBLAS, so for seeded sampling the stock kernel is DeepGEMM's; the \modelcons{} covers it, and the \modelhopper{} has not been checked for it.

\begin{theorem}[Certified race]\label{thm:race}
For a fixed noise vector $g$ and $T>0$, the ladder with $f_i(x)=x/T+g_i$ returns the token of a dense race with the same $g$ and tie rule. If the $g_i$ are i.i.d.\ standard Gumbel and independent of $z$, that token has law $\softmax(z/T)$.
\end{theorem}
\begin{proof}
Theorem~\ref{thm:ladder} and the Gumbel-max identity~\cite{gumbel1954,papandreou2011}; ties have probability zero.
\end{proof}
Bounding the perturbed scores so that most of them need not be computed is the principle of A$^\ast$ Sampling and of lazy Gumbel sampling~\cite{astar,mussmann2017}; a keyed field adds pathwise equality with the dense race (Appendix~\ref{app:fixednoise}).

\begin{theorem}[Fixed-noise verification]\label{thm:fixednoise}
Let $G_{t,i}$ be keyed by (seed, absolute position $t$, token $i$) and i.i.d.\ standard Gumbel, and let $Y_t=\min\argmax_i(z_{t,i}(Y_{<t})/T+G_{t,i})$. A speculative decoder that accepts a drafted token if and only if it equals $\argmax_i(z_{t,i}(x_{<t})/T+G_{t,i})$ at its drafted prefix, and emits that argmax at the first mismatch, outputs $Y$ for every drafter and every rule for how many tokens to draft, and $Y$ has the target's autoregressive law.
\end{theorem}\label{sec:fixednoise}
\paragraph{What it gives, and what it costs} This is the drafter-invariant construction of \citet{daliri2025}; it turns sampled verification into an argmax that Theorem~\ref{thm:race} certifies. With exactly the stock seeded noise, the certified path is equal in law to target sampling and independent of the drafter. It also returns the token the stock seeded sampler would return from the verify pass's own BF16 logits, provided that positions whose race the certificate cannot decide, under the stock rounding of the softmax and logarithm, go to the stock sampler. That is equality with seeded verification, not with non-speculative seeded decoding, whose logits can differ (Appendix~\ref{app:divergence}). The price is acceptance: for drafts that are themselves sampled, fixed-noise verification accepts at most as often as the standard rule and at least half as often, while for SGLang's default deterministic drafts the two accept equally often (Appendix~\ref{app:coupling}).

\paragraph{Evidence} On the kernel replay (Table~\ref{tab:sources}) at $T=0.7$ and 1, the certified sampler with its fallback returned the stock seeded token at every position \ev{kernel-seeded}. In the engine check (MTP-4B, eight requests, $T=0.7$; Section~\ref{sec:engine}) it did so at all 21,016 verification positions, 1.84\% of them through the fallback \ev{kernel-engine}. Its acceptance against the stock rejection-sampling verifier is not yet measured \pend{kernel-seeded-engine}, and the standard acceptance rule and residual races are analysed, not built (Appendix~\ref{app:sampling}).

\subsection{The Kernel}\label{sec:kernel-design}
The certified path for $M$ head inputs runs as a short pipeline with grids fixed by $M$, recorded as a CUDA graph once per batch size together with its fallback. An int8 pass multiplies int8 weights by the BF16 head inputs (W8A16), accumulates on tensor cores in FP32, and evaluates the error bound in its epilogue with directed rounding. Instead of writing the $M\times V$ logits it keeps, for each tile of vocabulary entries, the four largest upper bounds and one upper bound for the rest of the tile. Compaction gathers the candidates for steps 3 to 5 above. A kernel inherits the error bound only if it computes the modelled arithmetic, which is checked, not proved: each compiled variant must pass a self-test before it certifies, and every call checks eight exactly computed vocabulary entries per position \ev{kernel-impl}. The checks have caught faulty compiled tiles, which are now refused (Appendix~\ref{app:kernel-checks}) \ev{kernel-tma,triton-tma}.
