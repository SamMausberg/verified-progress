\section{The Certified Head}\label{sec:selfevidence}\label{sec:head}
The certified head decides each position from an int8 copy of $W$ evaluated at the target's own head input, in five steps.\label{sec:ladder}
\begin{enumerate}[leftmargin=1.4em]
\item Evaluate the int8 copy for every entry and form intervals $[\lo_i,\hi_i]=\tilde z_i\mp\beta_i$ that contain the real logits under the assumptions of Theorem~\ref{thm:envelope}.
\item Keep as \emph{candidates} the entries with $\hi_i\ge\max_j\lo_j-\delta_{\max}$; given valid intervals, no other entry can be the stock token (Section~\ref{sec:headcontracts}).
\item Recompute each candidate's real logit from its BF16 row in FP64 (whose tiny rounding error is added) and widen it by $G_i$ to an interval for the stock kernel's accumulator.
\item Round these intervals to BF16 and apply Proposition~\ref{prop:stockinterval}; if it fixes a token, emit it.
\item Otherwise send the position to a fallback (Section~\ref{sec:kernel-fallback}).
\end{enumerate}
The screen changes which entries are recomputed, never which decisions stay open: each entry it drops loses to the stock token under every admissible accumulation. Without $\delta_{\max}$, the same steps decide the \Rreal{} token; Appendix~\ref{app:ladder} states the general refinement and what of it is machine-checked. A call costs one pass over the int8 copy (half the stock head's weight bytes), candidate selection, recomputation and any fallback (Equation~\ref{eq:headgate}). The copy takes 0.64~GB beside the resident BF16 head (derived).

\subsection{An Error Bound for the Int8 Copy}\label{sec:envelope}\label{sec:accumulation}
The deployed copy stores row $i$ as int8 codes $q_i$ with one scale $s_i$; $\bar w_i=s_iq_i$ approximates $w_i$ with known error $e_i=w_i-\bar w_i$. The int8 pass multiplies the codes by the BF16 head input and sums in FP32 on tensor cores. Their adders align several addends to the largest, truncate them and round once~\cite{fasi2021}, so the standard bound for IEEE additions~\cite{higham2002} does not apply. We bound the sum's error by $\gamma_{\rm copy}\sum_j|\bar w_{ij}h_j|$ with the conservative constant, $\gamma_{\rm copy}=\gcons$, which covers the accumulations the \modelcons{} lists in Section~\ref{sec:headcontracts} (Lemma~\ref{lem:tree}, Appendix~\ref{app:accumulation}). This too is a hardware assumption, the conservative one under either stock-kernel model.

\begin{theorem}[Error bound of the copy]\label{thm:envelope}
If every product is exact in FP32 and the pass's accumulation error is at most $\gamma_{\rm copy}\sum_j|\bar w_{ij}h_j|$ plus an underflow floor $\eta'$, its value $\tilde z_i$ satisfies $|z_i-\tilde z_i|\le\beta_i=\norm{e_i}_2\norm h_2+\gamma_{\rm copy}\norm{\bar w_i}_2\norm h_2+\eta'$.
\end{theorem}
The kernel rounds the norms of $h$ up and the interval ends outward, so each comparison it computes is sound if it evaluates the analysed operations (Table~\ref{tab:assumptions}). The term $\norm{e_i}_2\norm h_2$ assumes the worst alignment of $e_i$ and $h$ and is loose: its median on captured states is 1.00 logit, about 75 times the median realized error $|\langle e_i,h\rangle|$ \ev{stats}. Appendix~\ref{app:proofs} proves a general form (Theorem~\ref{thm:envelope-general}) and gives $\eta'$.

\subsection{Seeded Sampling and Fixed-Noise Verification}\label{sec:decisions}\label{sec:race}\label{sec:fixednoise}
With a seed and no top-$k$ or top-$p$ truncation, SGLang samples a token as the winner of a race: it adds Gumbel noise to the log-probabilities and takes the argmax~\cite{sglangsampler}. The noise comes from a 32-bit hash of (seed, token position in the sequence, token). Because it is fixed before any score is known, the five steps applied to the noisy scores certify the race's winner (Appendix~\ref{app:sampling}). SGLang's seeded sampler exists only in its deterministic-inference mode, whose head kernel is DeepGEMM's, not cuBLAS. By code reading the \modelcons{} covers that kernel; the \modelhopper{} is unchecked for it. With its fallback, the certified decision matched the sampler on all 60,000 captured positions replayed through the kernel at $T=0.7$ and 1, on the same logits \ev{kernel-seeded}, and on all 21,016 verification positions in SGLang at $T=0.7$ \ev{kernel-engine}.

We also implemented \emph{fixed-noise verification}~\cite{daliri2025}, which accepts a drafted token exactly when it wins the target's race at its position. Against SGLang's rejection-sampling verifier, which it replaces, it accepts deterministic drafts (SGLang's default) as often and, by Proposition~\ref{prop:coupling}, sampled drafts at least half as often (Appendix~\ref{app:coupling}). It follows the target's distribution only for idealized continuous noise and prefix-only logits, which the engine does not guarantee (Appendix~\ref{app:fixednoise}). Its acceptance on real drafts was not measured.

\subsection{The Kernel}\label{sec:kernel-design}
One CUDA graph per batch size records the certified head and its fallback: a pipeline of GPU launches whose grids depend only on $M$. The int8 pass is a W8A16 GEMM (int8 weights, BF16 head inputs) that computes each interval in its epilogue with directed rounding. Instead of writing the $M\times V$ logits, each GPU program keeps, per position and vocabulary chunk, the four largest upper ends and the largest of the rest. A selection step then keeps every stored entry that reaches the screen's threshold, or the whole chunk if the rest's largest does, so no candidate is lost. A position whose candidates overflow the list's fixed capacity goes to the whole-batch fallback. The bound holds only for a kernel that computes the modelled arithmetic. That is checked, not proved: each compiled variant must pass a self-test before it certifies, and every call checks eight exactly computed entries per position \ev{kernel-impl}. Checks caught two faults, both refused. One gave wrong products from int8 tiles that Triton 3.7.1 loads in boxes 64 bytes wide through the Tensor Memory Accelerator (TMA), Hopper's tile-copy unit (Appendix~\ref{app:kernel-checks}) \ev{kernel-tma,triton-tma}.
