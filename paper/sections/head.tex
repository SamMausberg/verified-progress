\section{The Certified Head}\label{sec:selfevidence}\label{sec:head}
The certified head finds the \Rstock{} token from an int8 copy of $W$ evaluated at the target's own head input.

\subsection{An Error Bound for the Int8 Copy}\label{sec:envelope}\label{sec:accumulation}
The deployed copy stores each row as int8 codes $q_i$ with one scale $s_i$, so $\bar w_i=s_iq_i$ approximates $w_i$ with a known error $e_i=w_i-\bar w_i$. The pass that evaluates it multiplies the codes by the BF16 head input and sums in FP32 on tensor cores, whose adders align several addends to the largest, truncate them and round once~\cite{fasi2021}; a bound for IEEE additions~\cite{higham2002} does not cover them. We bound that sum's error by $\gamma_{\rm copy}\sum_j|\bar w_{ij}h_j|$ with the conservative constant, $\gamma_{\rm copy}=\gcons$, whatever model is assumed for the stock kernel; Lemma~\ref{lem:tree} (Appendix~\ref{app:accumulation}) shows that this covers any summation order and truncating adders.

\begin{theorem}[Error bound of the copy]\label{thm:envelope}
If every product is exact in FP32 and the pass's accumulation error is at most $\gamma_{\rm copy}\sum_j|\bar w_{ij}h_j|$ plus an underflow floor $\eta'$, its value $\tilde z_i$ satisfies $|z_i-\tilde z_i|\le\beta_i=\norm{e_i}_2\norm h_2+\gamma_{\rm copy}\norm{\bar w_i}_2\norm h_2+\eta'$.
\end{theorem}
Appendix~\ref{app:proofs} proves the general form (group scales, exact outlier columns, blockwise bounds; Theorem~\ref{thm:envelope-general}) and gives $\eta'$. We call $\beta_i$, the half-width of entry $i$'s interval $\tilde z_i\mp\beta_i$, the copy's \emph{error bound}. The kernel rounds the norms of $h$ up and the interval ends outward, so every computed comparison is sound, provided it evaluates the analysed operations (Table~\ref{tab:assumptions}). The screen therefore rests on a hardware assumption too, but always the conservative one; the \modelhopper{} enters only through the stock kernel's $G_i$. The bound assumes the worst alignment of $e_i$ and $h$, so it is loose: its median on captured states is 1.00 logit, about 75 times the median realized error \ev{stats}.

\subsection{Refinement Against the Stock Kernel}\label{sec:ladder}
The certified head decides each position in five steps.
\begin{enumerate}[leftmargin=1.4em]
\item Evaluate the int8 copy for every entry and form the intervals $[lo_i,hi_i]=\tilde z_i\mp\beta_i$ (Theorem~\ref{thm:envelope}).
\item Keep as \emph{candidates} the entries with $hi_i\ge\max_jlo_j-\delta_{\max}$; given valid intervals, no other entry can be the stock token (Section~\ref{sec:headcontracts}).
\item Recompute each candidate's real logit from its BF16 row in FP64 (whose tiny rounding error is added) and widen it by $G_i$ to an interval for the stock kernel's accumulator.
\item Round these intervals to BF16 and apply Proposition~\ref{prop:stockinterval}; if it fixes a token, emit it.
\item Otherwise send the position to a fallback (Section~\ref{sec:kernel-fallback}).
\end{enumerate}
The screen in step 2 changes which entries are recomputed, never which decisions stay open, because an entry it drops loses to the stock token under every admissible accumulation. The same steps, with $\delta_{\max}$ removed, decide the \Rreal{} token; Appendix~\ref{app:ladder} states the general refinement and what of it is machine-checked.

\subsection{Seeded Sampling and Fixed-Noise Verification}\label{sec:decisions}\label{sec:race}\label{sec:fixednoise}
With a seed and no top-$k$ or top-$p$ truncation, SGLang samples a token as the winner of a race: it adds Gumbel noise, computed from a 32-bit hash of (seed, sequence index, token), to the log-probabilities and takes the argmax. Because the noise is fixed before any score is known, the same five steps certify the race's winner, with the bounds applied to the noisy scores (Appendix~\ref{app:sampling}). \emph{Seeded verification} uses that race to check sampled drafts: a drafted token is accepted exactly when it wins the target's race at its position (\emph{fixed-noise verification}~\cite{daliri2025}). We implemented it in SGLang as part of our engine patches.

This is a change of rule, not a faster version of SGLang's speculative sampler, which verifies drafts by rejection sampling. For sampled drafts, fixed-noise verification can accept as little as half as often; for deterministic drafts, SGLang's default, it accepts as often (Appendix~\ref{app:coupling}). Its output follows the target's sampling distribution only for idealized continuous noise and logits that depend only on the prefix, which the 32-bit hash and the engine do not guarantee (Appendix~\ref{app:fixednoise}). The stock seeded sampler exists only in SGLang's deterministic-inference mode, whose head kernel is DeepGEMM's deterministic GEMM rather than cuBLAS; the \modelcons{} covers it, and the \modelhopper{} has not been checked for it.

What is measured is token equality with the stock seeded sampler on the same logits. In the kernel replay at $T=0.7$ and 1, the certified decision with its fallback returned, at every one of 60,000 positions, the token SGLang's seeded sampler gives for the cuBLAS BF16 logits of the same head input \ev{kernel-seeded}. In the engine check at $T=0.7$, in deterministic mode with the DeepGEMM head, it did so at all 21,016 verification positions (Section~\ref{sec:engine}) \ev{kernel-engine}. Its acceptance rate against the stock rejection-sampling verifier is not yet measured \pend{kernel-seeded-engine}.

\subsection{The Kernel}\label{sec:kernel-design}
The certified head for $M$ head inputs runs as a short pipeline with grids fixed by $M$, recorded as a CUDA graph once per batch size together with its fallback. The int8 pass multiplies int8 weights by the BF16 head inputs (W8A16), accumulates on tensor cores in FP32, and evaluates the error bound in its epilogue with directed rounding. Instead of writing the $M\times V$ logits, each block of vocabulary entries it processes keeps its four largest upper bounds and one bound for the rest of the block; a block whose remaining bound still reaches the threshold has all its entries kept, so compaction into a candidate list of fixed capacity loses no candidate, and a position whose list overflows goes to the whole-batch fallback. A kernel inherits the error bound only if it computes the modelled arithmetic, which is checked, not proved: each compiled variant must pass a self-test before it certifies, and every call checks eight exactly computed vocabulary entries per position \ev{kernel-impl}. The checks have caught faulty compiled kernel configurations, which are now refused (Appendix~\ref{app:kernel-checks}) \ev{kernel-tma,triton-tma}. The int8 copy, 0.64~GB, is held in addition to the resident BF16 head (derived).
