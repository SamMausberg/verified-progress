The CPU evidence (the exact references, the contract and state-structure witnesses, the synthetic experiment and the Lean check) is reproduced from the repository root with Python 3.13, NumPy and, for the formal files, Lean 4.19.0:
\par\noindent\begin{minipage}{\linewidth}
\begin{verbatim}
python -m venv .venv && . .venv/bin/activate
python -m pip install -r requirements-cpu.txt -r requirements-dev.txt
python scripts/verify_artifact.py        # rational references, synthetic drift, Lean check
python tests/test_precision.py           # exact floating-point reference
python tests/test_contracts.py           # contract witnesses
python tests/test_state_structure.py     # recurrent-state witnesses
python -m pytest tests/                  # every CPU test; GPU tests skip without CUDA
\end{verbatim}
\end{minipage}\par\smallskip
The GPU experiments need the hardware and engine of Appendix~\ref{app:pins}: one GH200 and the engine at the pin with the patches under \path{engine/sglang/patches/}; \path{engine/sglang/README.md} gives the commands that apply each series. Every evidence directory's \code{README.md} lists the exact command behind each file, and \code{RUNBOOK.md} collects the procedures. Timed runs were taken with exclusive use of the GPU and with the CPU load of other processes recorded for every point. The paper builds with \code{latexmk -pdf paper.tex} in \path{paper/} (pdfLaTeX and BibTeX, no shell escape); the build fetches the MLSys style file from the official kit and checks its SHA-256 digest (\path{paper/template/README.md}), and a figure whose data file is absent builds as a marked placeholder.
