\section{Introduction}\label{sec:intro}\label{sec:question}
In speculative decoding a cheap drafter proposes several tokens and the target model checks them all in one forward pass~\cite{specdecode,chen2023specsampling}. At each checked position the target multiplies its final hidden state, the \emph{head input}, by the output head, which gives a score (logit) for every vocabulary entry. A greedy verifier uses one fact from those scores, which entry is largest, and accepts a drafted token if and only if it is that entry. Plain greedy decoding makes the same single use of the head. Any shortcut through the head must therefore return exactly that token, and this paper's core is what ``exactly'' has to mean inside a production engine.

The speed at stake is modest. For Qwen3.5-4B the head has 248,320 entries; in BF16 it is 15\% of the weights a plain decode step reads (derived from the checkpoint; Appendix~\ref{app:bytes}). On a GH200 at batch 1 it takes 10.3\% of a plain decode step \ev{profile-head}, so even a free head would speed up such a step by only about 11\%. In a speculative cycle with the model's one-layer multi-token-prediction drafter (MTP-4B below), the target's verification head takes 4.4\% \ev{profile-attr} (Figure~\ref{fig:breakdown}). The drafter's own projections through the same head take a further 12.9\% of that cycle, and other work attributes 49\% of an EAGLE-2 drafter's time on Llama-3-8B to its head~\cite{frspec}. A certified head could serve those projections too. There, matching the stock token keeps the drafts, and so the acceptance rate, unchanged; the output's correctness does not depend on it.

Most of the head's computation goes to entries that cannot win, and it can be skipped by bounding instead of computing (Figure~\ref{fig:mechanism}). First, approximate every score cheaply, here from an int8 copy of the head, which reads half the bytes. Second, bound each approximation's error, so that every entry gets an interval guaranteed to contain its exact score. Third, discard every entry whose interval cannot reach the leader's, and recompute the few that remain exactly. Fourth, when the bounds still cannot single out the winner, fall back to the full computation. This pays when the intervals are narrow compared with the gap between the two best scores, as they are on this model (Section~\ref{sec:candidates}). Certified greedy screening of an LM head has public implementations~\cite{sparkpipehead,dgpphead,lagunaprune,knlphead}, and exact sampling from bounded scores is older~\cite{astar,mussmann2017}; Section~\ref{sec:related} compares them.

The hard part is deciding what the cheap computation must agree with, because the engine does not compute exact scores. It sums each logit in FP32, in an order its kernel chooses, rounds the sum to BF16, and returns the first index among equal maxima. BF16 keeps eight significant bits, so logits between 16 and 32 are 0.125 apart. In a hypothetical case, logits of 20.02 and 20.05 both round to 20.0. The engine then returns whichever entry has the lower index, even if its exact score is the smaller. On the captured greedy positions of this model, the engine's two largest logits tie in BF16 at 1.0\%, and the exact-arithmetic winner differs from the engine's token at about 0.5\% \ev{alignment}.

We therefore take the engine's own head as the reference: a certified head must return the token the unmodified (stock) head returns for the same head input at the same batch shape. That makes it a drop-in replacement whose correctness can be tested by bit-equality against the unmodified engine in the same configuration. We prove when intervals around the stock kernel's FP32 sums, before rounding, fix that token (Section~\ref{sec:contract}). The proof needs a bound on the kernel's rounding error, which no vendor documents, so we assume one under two named error models and test it. Positions the intervals cannot decide run the stock head, so a failed certificate costs time, not agreement; a certified token can be wrong only if an assumption of Table~\ref{tab:assumptions} fails.

We also test a second source of bounds, which we call \emph{transport}. A drafter that projects through the same head, such as MTP-4B or the public DFlash block drafter for this model (DFlash-4B), computes every logit at its own head input, and summaries of them per tile of 64 entries (the largest score and the sum of exponentiated scores) would cost little more. A Cauchy--Schwarz bound can carry those summaries to the target's head input, so the verifier would reuse work already paid for. Those bounds are sound, but they beat the int8 copy only if the \emph{drift}, the distance between draft and target head inputs relative to the target's, is below about 1\% (Section~\ref{sec:crossover}). Its median is 92\% for DFlash-4B and 95\% for MTP-4B, so the transported certificates are too loose to skip more than 0.7\% of the vocabulary.

\subsection{Contributions}\label{sec:contributions}
What is new here is a certificate for the token of a closed-source production kernel. Such a kernel cannot be replicated, as the Metal implementation's stock kernel is~\cite{lagunaprune}, so we bound its error with a model instead. Specifically:
\begin{enumerate}[leftmargin=1.2em,itemsep=.3ex]
\item \emph{A contract against the engine's own head} (Section~\ref{sec:contract}): proved conditions under which intervals around the stock kernel's FP32 sums fix the stock head's token at the same batch shape, with the stock head as the fallback. The kernel's error bound is assumed and tested, not proved.
\item \emph{A bound for tensor-core accumulation and its extension to seeded sampling} (Section~\ref{sec:head}): the int8 copy's error bound covers adders that truncate, and the same decision certifies SGLang's seeded sampler. Each compiled kernel is checked, not proved, to compute the modelled arithmetic.
\item \emph{Measurements on the engine's own states and in serving} (Section~\ref{sec:measure}): recomputation, fallback and token agreement offline and inside the engine, the head's time in isolation, and the stock serving frontier with the engine changes timed against it; the certified head's effect on serving is not yet measured \pend{bench-cert}.
\item \emph{A negative result} (Section~\ref{sec:transport}): for both public drafters and every bound variant and tile layout tested, certified transport skips under 0.7\% of the vocabulary.
\end{enumerate}
